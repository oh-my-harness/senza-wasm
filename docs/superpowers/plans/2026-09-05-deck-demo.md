# Deck Demo（对话生成 HTML PPT）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增第三个浏览器 demo `deck.html`：用户对话描述需求，agent 通过 `writeSlide`/`deleteSlide` 工具逐页生成 HTML 幻灯片，右侧 16:9 舞台实时预览，支持多轮修改，一键下载自包含 `.html` 文件。

**Architecture:** 逻辑分层两处——`demo/deck.js` 是纯 ESM 模块（Deck 状态模型、工具闭包工厂、自包含文档组装器），无 DOM/localStorage 依赖，Node 测试直接 import；`demo/deck.html` 是纯 UI 壳（聊天流 + 预览舞台），复用 `common.js` 配置与 chat.html 的事件泵模式。渲染路径：工具闭包内的 hooks 触发 → `buildDeckDocument` → `iframe.srcdoc`。

**Tech Stack:** 原生 ES Module + wasm-bindgen（`EmbeddedAgent`）+ mock provider（测试）。零构建步骤、零外部依赖。

**Spec:** 本对话（2026-09-05）商定的设计，要点收录在本文件「设计决策」节。

## 设计决策（对话已定案）

1. **工具面（严格 json_schema）**：`writeSlide(index, title, html)` upsert 语义；`deleteSlide(index)`。每个 tool result 回显**当前 deck 大纲**（页码 + 标题）——模型每次落子后都能看到全局结构，改第 3 页时不用盲猜历史。
2. **多轮修改**：靠 facade 的 history 续接（`prompt()` 发送 `history + [user msg]`，工具轮的 tool_use/tool_result 天然在历史里）。
3. **跨刷新恢复的硬约束**（读源码确认）：`importSession` 只接受 `user`/`assistant` role，工具轮导出含 `tool_result` 条目会抛 `session entry role 'tool_result' is not importable`。因此：deck 状态（页内容）单独存 localStorage（`senza-deck-slides`）；LLM 会话在页面内用 `ensureAgent` + `importSession` try/catch 兜底（同 chat.html）；**当 agent 重建且 deck 非空而会话导入失败时，首条用户消息自动前缀当前大纲**，让模型拿回上下文。
4. **预览**：右侧 iframe `srcdoc` = `buildDeckDocument(deck, 刚写的页码)`；生成的文档内嵌翻页 JS（方向键 + 点击翻页 + `postMessage` 通道）；缺失页码（模型跳写 1、3）渲染骨架占位。
5. **下载**：`Blob` + `a[download]`，文件就是预览的自包含 HTML（与 `buildDeckDocument` 同源，`initialPage=1`）。
6. **字号单位用 vmin**（不是 px）：预览 iframe 和全屏下载文件同比例缩放。
7. **maxTurns: 24**：逐页工具调用的体面守卫。
8. token 成本不设防（用户明确）。

## Global Constraints

- 单文件页面 + 一个纯模块，**无构建步骤、无 CDN、无外部依赖**。
- `demo/deck.js` 不得 import `common.js`、不得触碰 `document`/`localStorage`（Node 测试直接 import 它）。
- 所有 UI 文案中文；视觉沿用现有 demo 语言：底色 `#0a0d14`、面板 `#161a23`、边框 `#262b36`、强调 `#8ab4f8`、消息样式复用 chat.html 的类名体系（`msg/user/assistant/toolcall/toolresult/error`）。
- 工具参数 schema 严格模式（`required` 全列，`minimum: 1`）。
- 提交信息英文 conventional commits（`feat(demo): …`）。
- 不改 `src/`、`tests/node_smoke.mjs`、`tests/node_multi_turn.mjs`、`demo/chat.html`、`demo/vale.html`。

// deck.js — Deck 状态模型 + 工具闭包工厂 + 自包含文档组装器。
// 纯模块：不 import common.js、不触碰 document/localStorage —— Node 测试直接 import。
// 持久化由宿主（deck.html）用 deck.sorted() / new Deck(entries) 完成。

export class Deck {
  /** entries: [[index, {title, html}], ...]（localStorage 恢复用） */
  constructor(entries) {
    this.slides = new Map(entries ?? []);
  }

  /** upsert：同 index 覆盖。 */
  write(index, title, html) {
    this.slides.set(index, { title, html });
  }

  /** 删页。成功返回 null；失败返回回给 LLM 的纠错文案。 */
  remove(index) {
    if (!this.slides.has(index)) return `ERROR: 第 ${index} 页不存在，未删除。`;
    this.slides.delete(index);
    return null;
  }

  maxIndex() {
    return this.slides.size ? Math.max(...this.slides.keys()) : 0;
  }

  /** 按页码排序的 [index, slide] 数组（持久化/组装用）。 */
  sorted() {
    return [...this.slides.entries()].sort((a, b) => a[0] - b[0]);
  }

  /** 大纲文本：回显进每个工具结果，模型的全局结构感。 */
  outline() {
    if (!this.slides.size) return "（空）";
    return this.sorted().map(([i, s]) => `${i}. ${s.title}`).join("\n");
  }
}

/**
 * 工具闭包工厂：writeSlide（upsert）/ deleteSlide。
 * hooks: { onWrite?(index), onDelete?(index) } —— 宿主的渲染入口。
 * 每个工具结果都带当前大纲（设计决策 1）。
 */
export function makeDeckTools(deck, hooks = {}) {
  const withOutline = (msg) =>
    JSON.stringify({ text: `${msg}\n\n当前大纲：\n${deck.outline()}` });

  return {
    register(agent) {
      agent.registerTool(
        "writeSlide", "写入（新增或覆盖）一页幻灯片",
        JSON.stringify({
          type: "object",
          properties: {
            index: { type: "integer", minimum: 1, description: "页码，从 1 开始" },
            title: { type: "string", description: "大纲里显示的页标题" },
            html: { type: "string", description: "单页内容：<section> 片段，内联样式" },
          },
          required: ["index", "title", "html"],
        }),
        async (argsJson) => {
          const { index, title, html } = JSON.parse(argsJson);
          deck.write(index, title, html);
          hooks.onWrite?.(index);
          return withOutline(`已写入第 ${index} 页「${title}」。`);
        });

      agent.registerTool(
        "deleteSlide", "删除一页幻灯片",
        JSON.stringify({
          type: "object",
          properties: { index: { type: "integer", minimum: 1, description: "页码" } },
          required: ["index"],
        }),
        async (argsJson) => {
          const { index } = JSON.parse(argsJson);
          const err = deck.remove(index);
          if (err) return withOutline(err);
          hooks.onDelete?.(index);
          return withOutline(`已删除第 ${index} 页。`);
        });
    },
  };
}

```js
/**
 * 组装自包含幻灯片文档（预览 srcdoc 与下载文件同源）。
 * initialPage：初始显示页（生成期跳到刚写的页；下载固定 1）。
 * 缺失页码渲染骨架占位 —— 生成过程的进度感。
 */
export function buildDeckDocument(deck, initialPage = 1) {
  const max = deck.maxIndex();
  if (!max) {
    return `<!doctype html><html lang="zh-CN"><head><meta charset="utf-8"><title>deck</title>
<style>html,body{height:100%;margin:0;background:#0d1017;color:#5b6472;
font:14px/1.6 -apple-system,"PingFang SC",sans-serif;display:grid;place-items:center}</style>
</head><body>暂无页面</body></html>`;
  }
  const first = deck.slides.get(1)?.title ?? "deck";
  let pages = "";
  for (let i = 1; i <= max; i++) {
    const s = deck.slides.get(i);
    pages += s
      ? `<div class="page" data-i="${i}"><div class="inner">${s.html}</div></div>\n`
      : `<div class="page skeleton" data-i="${i}"><div class="inner">
           <div class="bar" style="width:46%"></div><div class="bar" style="width:72%"></div>
           <div class="bar" style="width:58%"></div><div class="bar" style="width:34%"></div>
         </div></div>\n`;
  }
  return `<!doctype html>
<html lang="zh-CN">
<head>
<meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1">
<title>${first}</title>
<style>
  * { box-sizing: border-box; margin: 0; }
  html, body { height: 100%; background: #0d1017; overflow: hidden;
    font: 3.2vmin/1.55 -apple-system, "PingFang SC", "Noto Sans SC", sans-serif; }
  .page { position: fixed; inset: 0; display: none; }
  .page.on { display: block; }
  .page .inner { width: 100%; height: 100%; padding: 8vmin; }
  .page.skeleton .inner { display: flex; flex-direction: column; gap: 3vmin;
    justify-content: center; max-width: 72vw; margin: 0 auto; }
  .bar { height: 3.6vmin; border-radius: 1.8vmin; background: #1c2230;
    animation: shimmer 1.4s ease-in-out infinite; }
  @keyframes shimmer { 50% { opacity: .45; } }
  #pg { position: fixed; right: 3vmin; bottom: 2.4vmin; font-size: 2vmin;
    color: #5b6472; user-select: none; }
  .zone { position: fixed; top: 0; bottom: 0; width: 30%; cursor: pointer; }
  #zl { left: 0; } #zr { right: 0; }
</style>
</head>
<body>
${pages}
<div class="zone" id="zl"></div><div class="zone" id="zr"></div>
<div id="pg"></div>
<script>
  var pages = document.querySelectorAll(".page");
  var cur = Math.max(1, Math.min(${initialPage}, pages.length));
  function show(n) {
    cur = Math.max(1, Math.min(pages.length, n));
    pages.forEach(function (p, i) { p.classList.toggle("on", i === cur - 1); });
    document.getElementById("pg").textContent = cur + " / " + pages.length;
  }
  document.addEventListener("keydown", function (e) {
    if (e.key === "ArrowRight" || e.key === " " || e.key === "PageDown") { e.preventDefault(); show(cur + 1); }
    if (e.key === "ArrowLeft" || e.key === "PageUp") { e.preventDefault(); show(cur - 1); }
  });
  document.getElementById("zl").onclick = function () { show(cur - 1); };
  document.getElementById("zr").onclick = function () { show(cur + 1); };
  addEventListener("message", function (e) {
    if (e.data && e.data.deckGo) show(cur + e.data.deckGo);
    if (e.data && e.data.deckSet) show(e.data.deckSet);
  });
  show(cur);
</script>
</body>
</html>`;
}
```

import init, { EmbeddedAgent } from "../pkg-web/senza_wasm.js";
import { bindSettings, providerOpts } from "./common.js";
import { Deck, makeDeckTools, buildDeckDocument } from "./deck.js";

const $ = (id) => document.getElementById(id);
const log = $("log");

await init();

// ---------- deck 状态（localStorage 持久化；LLM 会话另算） ----------
const LS_KEY = "senza-deck-slides";
function restoreDeck() {
  try { return new Deck(JSON.parse(localStorage.getItem(LS_KEY)) || []); }
  catch { return new Deck(); }
}
let deck = restoreDeck();

function persist() { localStorage.setItem(LS_KEY, JSON.stringify(deck.sorted())); }

function render(page) {
  $("frame").srcdoc = buildDeckDocument(deck, page ?? 1);
  $("pages").textContent = `${deck.slides.size} 页`;
  $("download").disabled = !deck.slides.size;
  persist();
}
render(1);

// ---------- agent ----------
const SYSTEM_PROMPT = `你是演示文稿设计师，通过工具逐页构建 HTML 幻灯片。

页面规范（严格遵守）：
- 每页一次 writeSlide 调用，index 从 1 开始连续编号。
- html 参数是单页片段：一个顶层 <section>，全部内联样式。
- 画布 16:9 全屏；字号用 vmin：大标题 7vmin、小标题 5vmin、正文 3.2vmin、注释 2.2vmin。
- 配色：背景 #161a23，主文字 #e8ebf0，强调色 #8ab4f8，弱文字 #9aa3b0。
- <section> 样式起点：width:100vw;height:100vh;box-sizing:border-box;padding:8vmin;background:#161a23;display:flex;flex-direction:column;justify-content:center
- 每页一个观点；要点不超过 5 条；可用 display:flex 两栏（gap:6vmin）。
- 不写 <html>/<head>/<body>/<script>，纯内容片段。

工作流：
- 用户要新 deck：先在心里规划页标题，再逐页 writeSlide。
- 修改：writeSlide 覆盖同 index；删页：deleteSlide。
- 每次工具结果都带当前大纲——改动后保持页码连续。
- 完成后用一两句中文说明结构，不要复述页面内容。`;

let agent = null;
let lastSessionJson = null;
let needsDeckContext = false; // agent 重建且 deck 非空 → 首条消息注入大纲

function makeAgent() {
  const a = new EmbeddedAgent(JSON.stringify(providerOpts({
    systemPrompt: SYSTEM_PROMPT,
    maxTurns: 24,
  })));
  makeDeckTools(deck, {
    onWrite: (i) => render(i),
    onDelete: () => render(1),
  }).register(a);
  return a;
}

function ensureAgent() {
  if (!agent) {
    agent = makeAgent();
    let imported = false;
    if (lastSessionJson) {
      try { agent.importSession(lastSessionJson); imported = true; } catch { /* 工具轮不可导入 → 重开 */ }
    }
    // 会话没接上但 deck 还在：首条消息带大纲，模型拿回上下文
    if (deck.slides.size && !imported) needsDeckContext = true;
  }
  return agent;
}
setInterval(() => { if (agent) lastSessionJson = agent.exportSession(); }, 3000);

// ---------- 事件泵（结构同 chat.html，无审批分支） ----------
let agentActive = false;
let currentAssistantBody = null;

function addMsg(cls, who, bodyText) {
  const div = document.createElement("div");
  div.className = `msg ${cls}`;
  const whoEl = document.createElement("div"); whoEl.textContent = who;
  const body = document.createElement("div"); body.className = "body";
  body.textContent = bodyText;
  div.append(whoEl, body);
  log.appendChild(div);
  log.scrollTop = log.scrollHeight;
  return body;
}
const busyEl = () => {
  const b = addMsg("assistant", "assistant", "");
  const c = document.createElement("span"); c.className = "cursor"; b.appendChild(c);
  return b;
};

async function pump() {
  for (;;) {
    await new Promise((r) => setTimeout(r, 40));
    const lines = agent.poll();
    for (const line of lines) handleEvent(JSON.parse(line));
    if (!lines.length && !agentActive) break;
  }
}

function handleEvent(ev) {
  switch (ev.type) {
    case "agent_start":
      agentActive = true;
      $("busy").classList.add("on");
      currentAssistantBody = busyEl();
      break;
    case "message_start":
      if (currentAssistantBody) currentAssistantBody.querySelector?.(".cursor")?.remove();
      currentAssistantBody = busyEl();
      break;
    case "text_delta":
      if (currentAssistantBody) {
        currentAssistantBody.lastChild?.classList?.remove("cursor");
        currentAssistantBody.append(ev.text);
        log.scrollTop = log.scrollHeight;
      }
      break;
    case "tool_execution_start":
      addMsg("toolcall", "tool call", `→ ${ev.tool_name}(${ev.args ?? ""})`);
      break;
    case "tool_execution_end":
      addMsg("toolresult", "tool result",
        ev.ok ? "✓ " + (ev.result?.text ?? JSON.stringify(ev.result)) : "✗ " + (ev.error ?? "failed"));
      break;
    case "message_end":
      if (currentAssistantBody) {
        currentAssistantBody.lastChild?.classList?.remove("cursor");
        currentAssistantBody = null;
      }
      break;
    case "agent_end":
      agentActive = false;
      $("busy").classList.remove("on");
      updateTokens();
      break;
    case "error":
      addMsg("error", "error", `${ev.error_type ?? ""}: ${ev.message ?? JSON.stringify(ev)}`);
      break;
  }
}

function updateTokens() {
  const c = JSON.parse(agent.costSnapshot());
  $("tokens").textContent = `${(c.totalInputTokens ?? 0) + (c.totalOutputTokens ?? 0)} tok`;
}

// ---------- wiring ----------
bindSettings({ preset: "preset", baseurl: "baseurl", apikey: "apikey", model: "model" },
  () => { agent = null; }); // 配置变更 → 下条消息重建 agent（deck 不动）

$("inputbar").onsubmit = (e) => {
  e.preventDefault();
  let text = $("input").value.trim();
  if (!text) return;
  try { ensureAgent(); } catch (err) {
    addMsg("error", "error", String(err.message ?? err));
    return;
  }
  if (needsDeckContext) {
    // 会话是新的但 deck 有内容：注入大纲让模型接上
    text = `（系统注入：当前 deck 已有内容，供你参考，不要复述）\n${deck.outline()}\n\n${text}`;
    needsDeckContext = false;
  }
  $("input").value = "";
  addMsg("user", "you", text);
  agent.prompt(text);
  pump();
};
$("input").onkeydown = (e) => {
  if (e.key === "Enter" && !e.shiftKey) { e.preventDefault(); $("inputbar").requestSubmit(); }
};

// 外层方向键 → 转发进 iframe（输入框聚焦时不抢）
document.addEventListener("keydown", (e) => {
  if (/^(INPUT|TEXTAREA)$/.test(document.activeElement?.tagName ?? "")) return;
  if (e.key === "ArrowRight") $("frame").contentWindow?.postMessage({ deckGo: 1 });
  if (e.key === "ArrowLeft") $("frame").contentWindow?.postMessage({ deckGo: -1 });
});

$("download").onclick = () => {
  const blob = new Blob([buildDeckDocument(deck, 1)], { type: "text/html" });
  const a = document.createElement("a");
  a.href = URL.createObjectURL(blob);
  a.download = `${(deck.slides.get(1)?.title ?? "deck").replace(/[\\/:*?"<>|]/g, "_")}.html`;
  a.click();
  URL.revokeObjectURL(a.href);
};

$("cleardeck").onclick = () => {
  if (!deck.slides.size && !agent) return;
  deck = new Deck();
  if (agent) { agent.clearSession(); lastSessionJson = null; }
  needsDeckContext = false;
  render(1);
  addMsg("assistant", "system", "deck 与会话已清空。");
};

addMsg("assistant", "system",
  "已就绪。描述你要的演示文稿（主题、页数、受众），模型会逐页生成，右侧实时预览。\n生成后可以继续对话修改：「第 2 页太啰嗦」「加一页讲风险」「把封面换成深蓝色」。");
</script>
</body>
